# Cosmic Coin Toss

Flip a realistic Indian ₹1 coin in deep space — React + React Three Fiber.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Stack

- Vite + React 19 + TypeScript
- React Three Fiber + Drei
- Procedural canvas textures for Ashoka-lion heads / ₹1 tails
- Web Audio procedural toss SFX
